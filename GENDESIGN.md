# Gendesign source provenance

Source: https://github.com/Niall-Young/Gendesign-Design-system

Revision: `af09961698140b80b0a5a06f3170896a76c8032d`

Imported UI components, their transitive component dependencies, `lib/utils.ts`, Nico tokens, and the upstream theme mapping retain their APIs and appearance except for the explicitly recorded application adaptations below. Update deliberately and review upstream instructions. The source repository declares no license; it is incorporated at its owner's request. Dependency licenses remain applicable.

## Consumption and verification

Icon source actions use the upstream LinkButton with its link color, default size, transparent background, and hover underline. GitHub actions use the MingCute brand icon. Application layout does not override LinkButton appearance or interaction states.

[gendesign-provenance.json](gendesign-provenance.json) records raw upstream and formatting-normalized SHA-256 checksums for the imported controls and their assets at the revision above. `npm test` checks normalized source fidelity. Message's `cn` import uses the equivalent `lib/utils.ts` re-export. Tree/TreeSelect have explicit owner-requested application adaptations: multiple selection renders the upstream Checkbox, selected labels use comma-space separators, and trigger, popup and row appearance share the application Select styles. The provenance retains upstream checksums and separately records adapted checksums. Public APIs and tree navigation remain unchanged.

Library options use Base UI Checkbox and Radio/RadioGroup primitives with a trailing MingCute check mark. The imported Checkbox and Radio controls do not support borderless menu rows at this revision; this application composition preserves selection and keyboard semantics without repainting their internal slots. Repository directories use the adapted TreeSelect/Tree with `multiple`: Cascader at this revision selects a single leaf and cannot preserve directory multiselection. The adapter only builds repository nodes and enforces the whole-repository and 20-directory rules. Inputs, password visibility, Tabs and popover motion retain upstream implementations.

NativeSelect is prohibited and is not imported. The application Select composes Base UI Select for flat single selection; its trigger uses the Nico Input background, borderless outline, radius, 32px height and focus/disabled tokens, plus a trailing MingCute dropdown arrow. It is an application composition, not an imported upstream Select. The application Select also supports multiple selection through Base UI Select, displays a Checkbox on each option, keeps the popup open during selection, and joins selected labels with comma-space separators. Repository directories use the adapted multiselect TreeSelect with the same appearance; there is no duplicate tag list below the field.

This revision has no Segmented, Menu or ContextMenu component. Grid/list selection composes Base UI Tabs primitives as an application Segmented matching Figma `2001:10239`: two 32px icon tabs, Nico neutral background, 8px radius, and an active surface with border and small shadow. Export format selection uses the application `Segmented` composition of Base UI Tabs matching Figma `2001:11710` (verified 2026-10-03): four equal-width 32px items (SVG, React, Vue and SwiftUI; the redundant HTML item is merged into SVG), no container padding, 14px regular text with 22px line height, Nico neutral background, 8px radius, and an active surface with border and small shadow. The imported Tabs source is unchanged. Application Segmented controls share a 260ms sliding surface with the existing border, radius and shadow. Tab-based segments use Base UI Tabs.Indicator to follow active-tab position and size, including unequal widths and resize; repository access uses an equal-width indicator under the existing RadioGroup. Pointer and keyboard selection retain Base UI semantics, and prefers-reduced-motion disables the transition. Modal MCP client selection composes Base UI Tabs as the same application Segmented, matching Figma `2018:13310` (retrieved 2026-10-03): 32px text-and-icon items without the instruction text, removed at the user’s request, with a 12px gap above an input-style code block that fills the remaining body space and scrolls independently. The dialog stays 640 × 615px across client switches and loading states, subject to the shared Modal viewport height limit. The footer uses the unchanged upstream LinkButton for the connection test. Settings-page MCP client selection composes Base UI Tabs as an application Segmented matching Figma `2023:18881`: 32px text-and-icon tabs, 4px icon gaps, Nico neutral background, and an active surface with border and small shadow. The heading and description sit beside the selection at wide widths and stack above it in narrow windows. Action popups compose upstream Popover and Button. Right-click menus require Base UI ContextMenu for trigger, focus and keyboard semantics, and render upstream Button for action appearance. These are application compositions, not upstream menu components. Application CSS must not repaint imported controls' internal appearance or hide their built-in icons.

Desktop component checks use controlled repository metadata through Electron IPC; the core integration test exercises real HTTPS Git with a local repository. These UI fixtures do not verify current public GitHub availability.

Settings navigation uses an application `SettingsMenuButton` composition of Base UI Button matching Figma `2023:18824`: 32px rows, 12px horizontal padding, 8px icon gap and radius, subtle text for back/unselected actions, and Nico neutral selected background with default text for the active section. The imported Button has no neutral side-menu variant at this revision; its source and interaction styles remain unchanged. Navigation SVGs retain their Figma provenance in `settings-provenance.json`.

Repository access selection composes Base UI RadioGroup and Radio as a text Segmented matching Figma `2018:11975` and `2023:19832`, since this imported revision has no Segmented control. It uses 32px segments and Nico neutral, surface, border, shadow and focus tokens while preserving radio keyboard and selection semantics. Both repository dialogs are 640 × 615px; the shared Modal viewport limit applies in short windows, with a scrolling body and fixed header/footer. Branch selection is always visible, and private credentials follow the repository link.

TreeSelect and Select use the same 16px arrow container with the Nico subtlest icon color. The container supplies the color because MingCute SVGs set inline `color: currentColor`. TreeSelect's clear action replaces the dropdown arrow in the same trailing slot on field hover or focus when the selection is nonempty and editable; otherwise the arrow is visible. The icons never appear together and swapping them does not move the value. The clear action matches InputClear: a 16px CloseCircleFilled icon, subtlest icon color, zero padding, circular shape and no border. It is omitted for empty, disabled and read-only selections. Mouse-down preserves focus, and clearing restores trigger focus. The upstream clear API and tree selection behavior are preserved.

Name fields use the application `CharacterLimitInput` composition around the unchanged upstream Input. It allows typing beyond the 20-character repository-name or 100-character display-name limit, uses `text-subtlest` for counters, mirrors overflowing text in the Nico negative color, and shows a MingCute warning with a field-level `valid-message` below the control. The recorded upstream revision has no ValidMessage component; this is an application composition. The native input retains caret, selection, paste, clear and IME behavior, and the visual mirror follows its size and horizontal scroll. The validation message is positioned below the input within the form’s existing 24px gap, with a 2px top inset and 20px line height. It adds no field height or extra spacing, so showing or clearing the single-line message does not move neighboring content. Over-limit names cannot be saved.

Global search matches Figma `2023:20291` and `2023:20613` (retrieved 2026-10-03): a 640px dialog with a flat 48px search input, 40px result rows, 16px library artwork and icon previews, grouped library/icon results, and a 60px footer with the application Segmented and an unchanged upstream tonal exit Button. The imported SearchBox has no flat 48px modal-header variant and the imported Button has no neutral selected menu-row appearance, so these two surfaces compose Base UI Input and Button directly with Nico tokens; their upstream sources are unchanged. Modal, IconButton and Spinner retain upstream APIs. Search and more icons are exported from the supplied Figma nodes with local provenance; library marks reuse the existing design assets, while the image-search control uses MingCute Attachment3Regular. Base UI Dialog retains focus trapping, dismissal and focus restoration; the application preserves IME handling and arrow/Enter navigation.

Library update notifications match Figma `2037:2668` (retrieved 2026-10-07) and compose Base UI Toast with the unchanged upstream filled, medium Button. The imported Message fixes its action to a small tonal button and its viewport to the top, so this minimal application composition supplies the required filled action, 24px gap, 12px radius, Nico medium shadow and bottom-80px placement. The 16px information SVG is localized with provenance in `src/renderer/design-assets/library-update/provenance.json`. Clicking the action dismisses immediately and acknowledges the revision; a 20-second wall-clock timeout dismisses without acknowledging, including during hover/focus. Navigating away cleans up the message and timer; a new library/revision gets a new message.

The recorded upstream revision has no removable image-tag component or 16px IconButton. The reference-image tag matches Figma `2037:2797` (retrieved 2026-10-07): 56 × 32px, a 24px thumbnail, 16px remove action, 4px gap and 4px/8px horizontal padding, with Nico neutral-subtle background and no text or border. It composes Base UI Button inside the existing SearchBox prefix API; the localized close asset and its provenance live in `src/renderer/design-assets/image-tag`. Uploading or pasting into a focused search input searches the full image directly. At the owner's request, application Input, Textarea and Select surfaces map their normal and hover input background tokens to Nico `surface`, except the library SearchBox, which retains the upstream grey input background; the global search header uses the raised surface. Upstream component sources and focus/disabled states remain unchanged.

The application Select accepts an optional leading visual per item and renders it in both the option row and the selected value while retaining plain string labels and Base UI keyboard selection. Theme selection uses this slot for Nico color dot previews; imported component sources remain unchanged.
